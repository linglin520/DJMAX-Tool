# DJMAX Tool

DJMAX RESPECT V 成绩查询与练习参考工具，原生 Android 应用，支持 Android 8.0 及以上。

作者：**鳕烩**。

## 主要功能

- **首页与优惠**：当期 CLEAR PASS、最新曲包轮播、六地区报价，音乐 DLC 搜索／新旧排序和近三个月价格历史。
- **通行证档案**：S1–S20 官方头图与期限、首页剩余天数，用户开启后最后 7 天每天最多一条本地通知。
- **理论值演示**：查分昵称输入 `理论值661229` 查看四模式全满分，名称明确显示“演示模式”，支持退出恢复原查询。

- **曲库查询**：歌曲列表／彩色曲包网格／等级分层视图、韩英曲名切换与双语搜索，开头匹配曲名优先于中间包含；逐曲新旧排序，曲包／彩色难度／收藏／MAX COMBO／PERFECT PLAY／自定义达成率范围筛选，BPM／总音符数／时长与曲绘缓存。
- **谱面特征**：本地 Hangibot 雷达，中文名称可点击查看原文和介绍；实线填色，部分缺轴按 0 绘制，整张无标注保留暂无数据。
- **成绩查询**：通过 V-ARCHIVE 昵称或用户查询 Token 查询 4B／5B／6B／8B 成绩，保留本地缓存；缺少某模式段位资料也能显示有效成绩，最高 Tier 无下一档正常处理。
- **BEST 100**：分别展示 B70／B30，S10 展示两组各最多 10 条接近入榜的已收录谱面；DJ POWER、DJ CLASS 与徽章汇总。
- **吃分推荐**：基于个人已收录成绩提供主推荐与候补，支持换一个、跳过和进度记录。
- **成长记录**：从成功查询开始积累 DJ POWER 与单谱面准确率曲线，查看成绩统计及近期记录。
- **整曲收藏**：保存整首歌曲，方便回查曲目与详情。
- **游戏入口**：右上角选择当前游戏；DJMAX 提供现有功能，PLATiNA :: LAB 为明确标注“开发中”的空白占位页。
- **外观与交互**：跟随系统／深色／浅色，默认银白，可选金色／樱花粉，保留已有主题选择；液态玻璃导航与圆形返回顶部，外观可独立开关玻璃磨砂和仅限状态栏的滚动模糊；曲库曲绘过渡、成绩整卡过渡、栏目淡变和刷新动效，新增模式水印／氛围光、雷达与曲线动效、菜单分组及更清晰的模式按钮。
- **App 搜索入口**：歌曲详情提供 YouTube 与 bilibili 两个 App 搜索入口，采用清晰矢量图标。
- **反馈入口**：“我的 → 关于”提供 BUG 反馈邮箱和“反馈QQ群”短标签，邮箱打开邮件应用，QQ群通过系统打开官方分享网页，再由页面处理 QQ 跳转。

## 下载与更新

安装包可从 [CNB Releases](https://cnb.cool/linglin520/DJMAX-Tool/-/releases) 或 [GitHub Releases](https://github.com/linglin520/DJMAX-Tool/releases/latest) 获取，提供 APK 和附带安装说明／摘要的 ZIP。两站发布同一安装包，使用相同签名覆盖安装，无需卸载；曲绘仍按需联网缓存。

当前版本为 **0.1.27**，四个主栏目的标题和游戏切换整行随页面滚动，滚出可见范围后隐藏，回到顶部恢复；保留状态栏透出与安全留白，顶部模糊仅限状态栏。可选择 CNB（默认）或 GitHub；每次启动只检查所选渠道一次，后台返回不重查，也可在“我的 → 关于”手动检查；失败不自动检查另一站。**点击“下载更新”才下载安装包**，备用下载仅使用本次进程内用户先前主动核对过的同版本、同摘要包，不为备用额外查版。下载完成并校验后，通过 Android 系统确认安装。0.1.15 及更旧版本可先通过网页或已有 GitHub 更新入口覆盖安装本版。

手动下载可显示系统进度通知，区分下载和校验，取消／完成后收起进度。小米设备携带公开超级岛协议，是否上岛由系统与应用准入决定；未支持时显示普通通知，通知权限关闭时仍可在应用内查看。当前尚未获得厂商正式上岛授权或完成小米真机验证。
